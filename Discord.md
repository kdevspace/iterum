#### #rules
> **Topic:** Community protocol — read before participating

```
⚙️  COMMUNITY PROTOCOL v1.0.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. RESPECT THE RUNTIME
   Every person here is running their own iteration.
   Respect their process, their pace, their path.

2. TRANSPARENCY OVER OBSCURITY
   Speak openly. Ask honestly. 
   No hidden agendas, no gatekeeping.

3. TEACH, DON'T PREACH
   Share knowledge without forcing beliefs.
   Iterum is an addition, never a replacement.

4. CODE QUALITY APPLIES TO WORDS
   Be clear, be kind, be constructive.
   Refactor hostility into curiosity.

5. NO DOGMA, NO HIERARCHY OF SOULS
   No one is "more enlightened." 
   Roles reflect contribution, not superiority.

6. OPEN SOURCE SPIRIT
   Ideas shared here belong to the community.
   Credit others. Fork freely. Merge generously.

7. BALANCE IS SACRED
   Don't glorify burnout. Rest is not a bug.
   Respect Sabbatum Digitale: protect attention from extraction.
   Meaningful work is allowed. Stolen runtime is not.

8. CONFLICT PROTOCOL
   try { direct dialogue }
   catch { invite a moderator }
   finally { learn and move forward }
   // NEVER: public shaming, doxxing, trolling

VIOLATIONS:
→ Warning (first offense)
→ Mute 24h (repeated)
→ Ban (toxic patterns)

By staying here, you accept this protocol.
Type /accept in #init to get @Initium role.
```
